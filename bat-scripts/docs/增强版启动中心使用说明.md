# 增强版启动中心使用说明

## 新增功能

### 数据清理选项

#### [9] Clean All Factor Data (NEW!)
- **功能**：清理所有因子相关数据
- **清理内容**：
  - 验证流程数据 (ValidationPipelineData)
  - 候选因子 (Candidate)
  - 进化任务 (EvolutionTask)
  - 代统计数据 (GenerationStats)
- **安全性**：需要确认才能执行，防止误操作

#### [10] Clean Data + Start Dev Mode (NEW!)
- **功能**：先清理数据，然后启动基础开发模式
- **适用场景**：需要完全重新开始调试时
- **流程**：
  1. 清理所有因子数据
  2. 启动基础开发模式

#### [11] Clean Data + Start Enhanced Mode (NEW!)
- **功能**：先清理数据，然后启动增强开发模式（含GPU检测）
- **适用场景**：需要完全重新开始，并使用GPU加速时
- **流程**：
  1. 清理所有因子数据
  2. 启动增强开发模式

## 使用步骤

### 场景1：仅清理数据
1. 运行 `启动中心_增强版.bat`
2. 选择 `[9] Clean All Factor Data`
3. 确认清理操作
4. 等待清理完成

### 场景2：清理后开始调试（推荐）
1. 运行 `启动中心_增强版.bat`
2. 选择 `[10] Clean Data + Start Dev Mode`（基础模式）
   - 或选择 `[11] Clean Data + Start Enhanced Mode`（增强模式）
3. 确认操作
4. 等待清理完成
5. 自动启动开发环境

### 场景3：原有功能
- 其他选项保持不变，与原版启动中心相同

## 安全特性

### 确认机制
- 所有清理操作都需要用户确认
- 默认选择为 "N"（不执行），防止误操作

### 错误处理
- 如果清理失败，不会启动开发环境
- 提供详细的错误信息

### 环境检测
- 自动检测Poetry环境
- 如果Poetry环境不可用，尝试使用系统Python

## 技术细节

### 清理脚本
- 使用 `scripts\cleanup\clean_data_simple.py`
- 该脚本专门处理核心数据表，避免数据库字段问题
- 清理后数据表完全清空

### 路径处理
- 自动检测项目根目录
- 支持相对路径和绝对路径
- 兼容不同的安装环境

## 注意事项

### 数据备份
- 清理操作不可逆
- 建议在清理前备份重要数据

### 系统要求
- 需要Python环境
- 需要数据库连接正常
- 建议关闭相关的开发环境

### 性能影响
- 清理大量数据可能需要一些时间
- 清理后首次启动可能需要重新初始化

## 故障排除

### 清理失败
1. 检查Python环境是否正常
2. 检查数据库连接
3. 查看错误日志

### 启动失败
1. 确认清理操作成功完成
2. 检查端口占用
3. 查看启动日志
