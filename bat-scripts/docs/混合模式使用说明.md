# 混合模式使用说明

## 概述

混合进化模式结合了通用因子和品种特定因子的优势，同时挖掘适用于多个品种的通用因子和仅适用于特定品种的专用因子。

## 启动方式

### 通过启动中心

1. 运行 `启动中心_增强版.bat`
2. 选择选项 `[19] Start Hybrid Evolution (Universal + Symbol-Specific)`
3. 系统将启动混合进化模式

### 直接运行脚本

```batch
start-hybrid-evolution.bat
```

## 配置说明

### 环境变量

- `ENABLE_EVOLUTION_POOL=1` - 启用进化池
- `ENABLE_SCHEDULER=0` - 禁用调度器
- `EVOLUTION_MODE=hybrid` - 设置为混合进化模式

### 通用因子权重

通过 `universal_weight` 参数控制通用因子和品种特定因子的权重：
- `0.0` - 仅品种特定因子
- `0.5` - 均衡（默认）
- `1.0` - 仅通用因子

## 使用流程

1. 启动后端服务
2. 运行混合进化脚本
3. 通过前端界面配置通用因子权重
4. 监控进化进度
5. 查看分类后的因子库

## 因子分类

系统会自动将因子分类为：
- **通用因子**：适用于多个品种
- **品种特定因子**：仅适用于特定品种
- **行业特定因子**：适用于同一行业的品种

## 注意事项

- 混合模式需要更多的计算资源
- 建议根据实际需求调整通用因子权重
- 定期检查因子分类结果，优化分类阈值

## 故障排除

### 分类不准确

如果因子分类结果不符合预期：
1. 调整泛化测试阈值
2. 增加测试品种数量
3. 检查数据质量
