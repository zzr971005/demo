# 联合进化启动说明

## 概述

联合进化模式用于在多个品种上同时进行因子挖掘，以发现适用于多个品种的通用因子（Universal Factors）。

## 启动方式

### 通过启动中心

1. 运行 `启动中心_增强版.bat`
2. 选择选项 `[18] Start Joint Evolution (Multi-Symbol)`
3. 系统将启动联合进化模式

### 直接运行脚本

```batch
start-joint-evolution.bat
```

## 配置说明

### 环境变量

- `ENABLE_EVOLUTION_POOL=1` - 启用进化池
- `ENABLE_SCHEDULER=0` - 禁用调度器
- `EVOLUTION_MODE=joint` - 设置为联合进化模式

### 前置条件

1. 后端服务必须已启动（端口8000）
2. PostgreSQL数据库必须运行
3. 数据库中必须有目标品种的历史数据

## 使用流程

1. 启动后端服务
2. 运行联合进化脚本
3. 通过前端界面监控进化进度
4. 查看生成的通用因子

## 注意事项

- 联合进化需要多个品种的数据，确保数据完整性
- 进化时间会随着品种数量增加而延长
- 建议先在少量品种上测试，确认效果后再扩展

## 故障排除

### 后端未启动

错误信息：`Backend is not running`

解决方法：先运行 `start-backend-only.bat` 启动后端

### 数据缺失

错误信息：`No data available for symbol`

解决方法：检查数据库中是否有目标品种的数据，必要时先运行数据初始化
