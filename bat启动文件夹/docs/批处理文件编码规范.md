# 批处理文件编码规范

## 问题背景

Windows 批处理文件（.bat）在使用中文时经常出现乱码问题，这是由于文件编码与命令提示符（cmd）默认编码不一致导致的。

## 根本原因

| 环境 | 默认编码 | 说明 |
|------|---------|------|
| Windows cmd | GBK (CP936) | 中文Windows默认代码页 |
| Python脚本 | UTF-8 | 现代编程默认编码 |
| 编辑器 | 通常UTF-8 | 如VS Code默认UTF-8 |

当批处理文件以UTF-8编码保存，但cmd使用GBK解析时，中文字符就会变成乱码。

## 行尾要求（⚠️ 重要）

**批处理文件必须使用 CRLF (`\r\n`) 行尾，禁止使用 LF (`\n`)。**

Windows cmd.exe 在双击运行 .bat 文件时，如果文件使用 LF-only 行尾，会导致解析错误并**直接闪退**（无任何错误提示）。

- ✅ **CRLF (`0x0D 0x0A`)** — Windows 标准行尾，cmd 正常解析
- ❌ **LF (`0x0A`)** — 类Unix行尾，双击运行时会闪退

> Windsurf / Trae IDE / VS Code 在 Windows 上保存文件时默认可能使用 LF 行尾。若发现双击 .bat 闪退，先用 [Notepad++](https://notepad-plus-plus.org/) 或 VS Code 右下角检查行尾格式，确保为 **CRLF**。

## 正确解决方案

### 方案：使用纯英文（推荐，且不需要chcp）

**最佳实践**：批处理文件完全使用英文，避免中文编码问题。内容全部为 ASCII 时，**不需要** `chcp` 命令，Windows 默认代码页即可完美运行。

> ⚠️ **重要**：`chcp 65001` 在部分 Windows 10/11 版本上存在已知 bug，执行后 `pause` 命令会失效，导致窗口闪退。由于英文内容在默认代码页(GBK/936)下显示正常，**切勿使用 `chcp 65001`**。

```batch
@echo off
setlocal enabledelayedexpansion
title Development Mode

echo.
echo ===============================
echo  Development Mode Startup
echo ===============================
echo.

set "SCRIPT_DIR=%~dp0"
for %%I in ("%SCRIPT_DIR%..") do set "PROJECT_ROOT=%%~fI"
set "BACKEND_PATH=%PROJECT_ROOT%\backend"
set "FRONTEND_PATH=%PROJECT_ROOT%\frontend"

echo [1/3] Checking environment...
echo [OK] Environment ready

echo.
echo [2/3] Select startup mode:
echo    [1] Start all services
echo    [2] Infrastructure only
echo    [3] Exit
echo.

set /p choice="Enter option: "
if "%choice%"=="1" goto :start_all
if "%choice%"=="2" goto :start_infra
if "%choice%"=="3" exit /b 0

goto :end

:start_all
echo Starting all services...
REM Start services here
goto :end

:start_infra
echo Starting infrastructure...
REM Start infrastructure here
goto :end

:end
echo Done.
pause
```

**优点**：
- 无需担心编码问题
- 在 cmd 和 PowerShell 中都能正常显示
- 兼容性好，不会出现乱码导致的命令解析错误

## 关键要点

### 1. 代码页设置

```batch
REM 内容纯英文时，不需要 chcp，使用默认代码页即可
REM 如需显示中文字符，使用 GBK (936)
chcp 936 >nul 2>&1
```

### 2. 路径处理

**正确做法**：使用 `for` 循环获取绝对路径

```batch
set "SCRIPT_DIR=%~dp0"
for %%I in ("%SCRIPT_DIR%..") do set "PROJECT_ROOT=%%~fI"
set "BACKEND_PATH=%PROJECT_ROOT%\backend"
set "FRONTEND_PATH=%PROJECT_ROOT%\frontend"
```

**错误做法**：直接使用 `..`
```batch
set "PROJECT_ROOT=%SCRIPT_DIR%.."  :: 可能导致路径解析错误
```

### 3. 端口选择

**重要**：避免使用 Windows 保留端口范围

检查排除端口范围：
```powershell
netsh int ipv4 show excludedportrange protocol=tcp
```

常见保留范围：
- 1026-1125
- 5141-5240
- 50000-50059

**推荐端口**：
- 前端：3000, 8080, 8081
- 后端：8000, 8001, 9000

### 4. 端口检查

检查所有可能的绑定地址：

```batch
REM Check IPv4
for /f "tokens=5" %%p in ('netstat -ano ^| findstr "0.0.0.0:%PORT%" ^| findstr "LISTENING"') do (
    taskkill /F /PID %%p >nul 2>&1
)

REM Check IPv6
for /f "tokens=5" %%p in ('netstat -ano ^| findstr "[::]:%PORT%" ^| findstr "LISTENING"') do (
    taskkill /F /PID %%p >nul 2>&1
)

REM Check localhost
for /f "tokens=5" %%p in ('netstat -ano ^| findstr "127.0.0.1:%PORT%" ^| findstr "LISTENING"') do (
    taskkill /F /PID %%p >nul 2>&1
)
```

### 5. 条件判断

使用简单变量比较：

```batch
if "%VAR%"=="1" (
    echo Variable is 1
) else (
    echo Variable is not 1
)
```

## 最终版本示例

### start-dev-pro.bat

```batch
@echo off
chcp 936 >nul 2>&1
title Development Mode

echo.
echo ===============================
echo  Development Mode Startup
echo ===============================
echo.

set "SCRIPT_DIR=%~dp0"
for %%I in ("%SCRIPT_DIR%..") do set "PROJECT_ROOT=%%~fI"
set "BACKEND_PATH=%PROJECT_ROOT%\backend"
set "FRONTEND_PATH=%PROJECT_ROOT%\frontend"
set "BACKEND_PORT=8000"
set "FRONTEND_PORT=3000"

REM Pre-check
echo [1/9] Environment pre-check...
echo.

REM Check PostgreSQL
echo    [Check] PostgreSQL...
sc query postgresql-x64-17 >nul 2>&1
if errorlevel 1 (
    echo    [Error] PostgreSQL not installed
    pause
    exit /b 1
)
echo    [OK] PostgreSQL available

REM Check Python virtual environment
echo    [Check] Python virtual environment...
for /f "delims=" %%i in ('cd /d "%BACKEND_PATH%" ^& poetry env info --path 2^>nul') do set "VENV_PATH=%%i"
if not defined VENV_PATH (
    echo    [Hint] Creating virtual environment...
    cd /d "%BACKEND_PATH%"
    poetry install --no-interaction
    for /f "delims=" %%i in ('cd /d "%BACKEND_PATH%" ^& poetry env info --path 2^>nul') do set "VENV_PATH=%%i"
)
set "PYTHON=%VENV_PATH%\Scripts\python.exe"
echo    [OK] Python environment ready

REM Check Node.js
echo    [Check] Node.js...
node --version >nul 2>&1
if errorlevel 1 (
    echo    [Error] Node.js not installed
    pause
    exit /b 1
)
echo    [OK] Node.js available

REM Check service status
echo.
echo [2/9] Checking service status...
echo.

set "INFRA_NEED_START=0"
set "BACKEND_NEED_START=0"
set "FRONTEND_NEED_START=0"

sc query postgresql-x64-17 | findstr "RUNNING" >nul
if errorlevel 1 (
    echo    [Infrastructure] Not running
    set "INFRA_NEED_START=1"
) else (
    echo    [Infrastructure] Running
)

netstat -ano | findstr "0.0.0.0:%BACKEND_PORT%" | findstr "LISTENING" >nul
if errorlevel 1 (
    echo    [Backend] Not running
    set "BACKEND_NEED_START=1"
) else (
    echo    [Backend] Running
)

netstat -ano | findstr "0.0.0.0:%FRONTEND_PORT%" | findstr "LISTENING" >nul
if errorlevel 1 (
    echo    [Frontend] Not running
    set "FRONTEND_NEED_START=1"
) else (
    echo    [Frontend] Running
)

REM Select startup mode
echo.
echo [3/9] Select startup mode:
echo.
echo    [1] Start all (Infrastructure + Backend + Frontend)
echo    [2] Infrastructure only
echo    [3] Backend only
echo    [4] Frontend only
echo    [5] Smart start (only missing services)
echo    [0] Exit
echo.

set /p choice="Enter option [0-5]: "

if "%choice%"=="0" exit /b 0
if "%choice%"=="1" (
    set "INFRA_NEED_START=1"
    set "BACKEND_NEED_START=1"
    set "FRONTEND_NEED_START=1"
)
if "%choice%"=="2" (
    set "INFRA_NEED_START=1"
    set "BACKEND_NEED_START=0"
    set "FRONTEND_NEED_START=0"
)
if "%choice%"=="3" (
    set "INFRA_NEED_START=1"
    set "BACKEND_NEED_START=1"
    set "FRONTEND_NEED_START=0"
)
if "%choice%"=="4" (
    set "INFRA_NEED_START=0"
    set "BACKEND_NEED_START=0"
    set "FRONTEND_NEED_START=1"
)
if "%choice%"=="5" (
    echo.
    echo [Hint] Smart mode: only start missing services
)

REM Start services
echo.
echo [4-9/9] Starting services...
echo.

REM Start infrastructure
if "%INFRA_NEED_START%"=="1" (
    echo    [Start] Infrastructure...
    cd /d "%PROJECT_ROOT%"
    net start postgresql-x64-17 >nul 2>&1
    net start redis >nul 2>&1
    echo    [OK] Infrastructure started
)

REM Check and cleanup backend port
if "%BACKEND_NEED_START%"=="1" (
    echo    [Check] Backend port...
    for /f "tokens=5" %%p in ('netstat -ano ^| findstr "0.0.0.0:%BACKEND_PORT%" ^| findstr "LISTENING"') do (
        echo    [Hint] Port %BACKEND_PORT% occupied, killing PID: %%p...
        taskkill /F /PID %%p >nul 2>&1
        timeout /t 1 /nobreak >nul
    )
    echo    [OK] Backend port ready
)

REM Check and cleanup frontend port
if "%FRONTEND_NEED_START%"=="1" (
    echo    [Check] Frontend port...
    for /f "tokens=5" %%p in ('netstat -ano ^| findstr "0.0.0.0:%FRONTEND_PORT%" ^| findstr "LISTENING"') do (
        echo    [Hint] Port %FRONTEND_PORT% occupied, killing PID: %%p...
        taskkill /F /PID %%p >nul 2>&1
        timeout /t 1 /nobreak >nul
    )
    for /f "tokens=5" %%p in ('netstat -ano ^| findstr "[::]:%FRONTEND_PORT%" ^| findstr "LISTENING"') do (
        echo    [Hint] IPv6 Port %FRONTEND_PORT% occupied, killing PID: %%p...
        taskkill /F /PID %%p >nul 2>&1
        timeout /t 1 /nobreak >nul
    )
    for /f "tokens=5" %%p in ('netstat -ano ^| findstr "127.0.0.1:%FRONTEND_PORT%" ^| findstr "LISTENING"') do (
        echo    [Hint] Localhost Port %FRONTEND_PORT% occupied, killing PID: %%p...
        taskkill /F /PID %%p >nul 2>&1
        timeout /t 1 /nobreak >nul
    )
    echo    [OK] Frontend port ready
)

REM Start backend
if "%BACKEND_NEED_START%"=="1" (
    echo    [Start] Backend service...
    echo    [Info] Port: %BACKEND_PORT%
    echo    [Hint] Ctrl+C to stop
    start "Backend - Port %BACKEND_PORT%" cmd /k cd /d "%BACKEND_PATH%" ^&^& set PYTHONPATH=%BACKEND_PATH% ^&^& "%PYTHON%" -m uvicorn app.main:app --host 0.0.0.0 --port %BACKEND_PORT% --reload --log-level info
    
    echo    [Wait] Starting backend...
    timeout /t 3 /nobreak >nul
)

REM Start frontend
if "%FRONTEND_NEED_START%"=="1" (
    echo    [Start] Frontend service...
    echo    [Info] Port: %FRONTEND_PORT%
    echo    [Hint] Ctrl+C to stop
    start "Frontend - Port %FRONTEND_PORT%" cmd /k cd /d "%FRONTEND_PATH%" ^&^& npm run dev
    
    echo    [Wait] Starting frontend...
    timeout /t 3 /nobreak >nul
)

REM Completion message
echo.
echo ===============================
echo  Startup complete!
echo ===============================
echo.
echo Service access:
echo    Frontend: http://localhost:%FRONTEND_PORT%
echo    Backend API: http://localhost:%BACKEND_PORT%
echo    API Docs: http://localhost:%BACKEND_PORT%/docs
echo.
echo Press any key to close this window (services will continue running)...
pause >nul
```

## 总结

| 要点 | 正确做法 |
|------|---------|
| 语言 | 使用纯英文，避免编码问题 |
| 行尾 | **CRLF (`\r\n`)**，禁止 LF-only，否则双击闪退 |
| 代码页 | 内容纯英文时**不需要** `chcp`；如需中文用 `chcp 936` |
| 路径处理 | 使用 `for %%I in ("%SCRIPT_DIR%..")` 获取绝对路径 |
| 端口选择 | 避开 Windows 保留端口范围 |
| 端口检查 | 检查 IPv4、IPv6 和 localhost |
| 条件判断 | 使用简单变量比较 `"%VAR%"=="1"` |
