## 📋 日常使用速查表

### 🌅 早上开始开发
```bash
# 1. 检查状态
check-status.bat

# 2. 智能启动（仅启动缺失的服务）
start-dev-pro.bat → 选项 5

# 3. [可选] 更新数据
init-data.bat → 选项 1 (增量更新)
```

### ⚡ 中途需要重启
```bash
# 完整重启
restart-all.bat

# 或者先清理再启动
stop-all.bat → clean-ports.bat → start-dev-pro.bat
```

### 🌙 开发结束
```bash
stop-all.bat
```

### 🔍 调试排错
```bash
# 先检查所有服务状态
check-status.bat

# 根据检查结果决定：
# - 端口冲突 → clean-ports.bat
# - 后端挂了 → start-backend-only.bat
# - 数据库问题 → 检查 PostgreSQL 服务
```

## 💡 使用技巧

### 1️⃣ 添加到快速访问
将 `bat启动文件夹` 添加到文件资源管理器的快速访问中：
- 右键 `bat启动文件夹` → 固定到快速访问
- 以后直接从快速访问双击运行

### 2️⃣ 创建桌面快捷方式
为常用脚本创建桌面快捷方式：
- 右键 `start-dev-pro.bat` → 发送到 → 桌面快捷方式
- 重命名为 "期货系统开发启动"

### 3️⃣ 同时运行多个脚本
- `check-status.bat` 可以随时运行（不影响服务）
- `clean-ports.bat` 可以随时运行（服务已停止时）

---

## ⚠️ 使用注意事项

### ✅ 推荐的操作顺序
1. 始终先运行 `check-status.bat` 了解当前状态
2. 再根据需要选择启动脚本
3. 停止时用 `stop-all.bat` 彻底清理

### ❌ 不要这样做
- ❌ 不要同时运行多个启动脚本（会端口冲突）
- ❌ 不要直接关闭 cmd 窗口杀服务 → 用 `stop-all.bat`
- ❌ 不要在 PostgreSQL/Redis 服务未启动时运行启动脚本

## 🆘 紧急情况处理

### 完全卡死？
```bash
# 1. 停止所有服务
stop-all.bat

# 2. 清理所有端口
clean-ports.bat

# 3. 重启基础服务
net start postgresql-x64-17
net start redis

# 4. 重新启动
start-dev-pro.bat
```

### 数据库出问题？
```bash
# 检查 PostgreSQL 服务状态
sc query postgresql-x64-17

# 检查 Redis 服务状态
sc query redis

# 重启服务
net stop postgresql-x64-17 & net start postgresql-x64-17
net stop redis & net start redis
```
