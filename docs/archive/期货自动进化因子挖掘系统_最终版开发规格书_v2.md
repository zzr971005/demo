# 期货自动进化因子挖掘系统 — 最终版开发规格书

> **版本**：v1.0 最终版  
> **目标**：一次性开发完成，直接部署运行  
> **市场**：国内期货（CTP via 天勤TqSdk）  
> **开发工具**：Trae (AI IDE)  
> **主周期**：1小时 (H1)，辅助日线Regime过滤  

---

## 一、项目定位与战略决策

### 1.1 放弃项
- **A股**：T+1制度对量化策略极不友好，数据成本高，程序化接口受限
- **加密货币**：虽有全天候优势，但永续合约资金费率、强平机制、API限频、合规风险构成双重学习曲线。本系统暂不接入，但架构预留扩展接口

### 1.2 核心目标
构建一个**12品种独立进化池**系统，能够：
1. 每晚自动运行遗传编程，挖掘新的因子组合策略
2. 每个品种维护趋势/波段/反转三类策略池，自动优胜劣汰
3. 模拟盘验证通过后，由用户手动开关决定是否进入实盘
4. 实盘运行中持续监控，回撤超限自动降级，新策略自动替换旧策略
5. 全流程可视化：全局监控、进化血缘追踪、品种详情、手动控制

## 三、周期设计：三周期金字塔

```
          ┌─────────┐
          │  日线   │  ← Regime过滤 + 仓位系数（权重20%）
          │ (D1)   │
          └────┬────┘
               ↓
          ┌─────────┐
          │  1小时  │  ← 主信号生成 + 策略进化（权重70%）
          │ (H1)   │
          └────┬────┘
               ↓
          ┌─────────┐
          │  5分钟  │  ← 仅执行优化：TWAP拆单、滑点控制（权重10%）
          │ (M5)   │
          └─────────┘
```

### 3.1 为什么选1小时作为主周期？
- **数据量**：商品含夜盘，一年约830根1小时K线，3年2500根，刚好在遗传编程有效样本边缘
- **信噪比**：能过滤大部分随机波动，保留日内波段和隔夜趋势
- **手续费**：平均持仓5-10小时，单次交易成本占本金0.1-0.15%，可接受
- **夜盘利用**：1小时K线自然拼接夜盘和日盘，捕捉"跳空+延续"模式

### 3.2 日线的作用
仅做Regime过滤，不做信号：
- `trend_strength = ts_corr(close_d, ts_mean(close_d, 20), 20)`
- 趋势强度>0.6时，1小时策略多头权重×1.5
- 高波动Regime时，1小时策略仓位减半

### 3.3 5分钟的作用
仅用于执行优化（拆单、入场点微调），不生成信号。避免在5分钟级别做因子挖掘（数据量虽大但过拟合极高）。

## 五、因子挖掘六层规范框架（核心！）

不是随机挖宝，是有地图的探险。

### 5.1 第1层：原语族化（Primitive Families）

按市场逻辑分成8个族，每个族有明确经济含义。策略模板强制要求**跨族组合**（至少2个不同族）。

| 族名 | 核心逻辑 | 原语示例 | 适用品种 |
|------|---------|---------|---------|
| **动量族** | 趋势延续 | `ts_return`, `ts_corr(close, ma, N)`, `cs_rank(ts_return)` | IF, RB, CU |
| **均值回归族** | 过度反应修复 | `zscore(close, N)`, `rsi`, `distance_from_ma` | MA, FG, 震荡期 |
| **波动率族** | 波动聚集/突破 | `ts_std`, `atr`, `ts_range`, `vol_regime` | AU, SC |
| **价量关系族** | 资金确认/背离 | `ts_corr(close, volume, N)`, `volume_zscore`, `obv` | RB, MA |
| **期限结构族** | 基差/展期收益 | `basis`, `roll_yield`, `spread_near_far` | 所有商品 |
| **持仓量族** | 筹码/情绪 | `oi_change`, `oi_price_divergence`, `oi_vol_ratio` | RB, MA |
| **微观结构族** | 盘口/订单流 | `night_gap`, `opening_range`, `intraday_range_ratio` | 夜盘品种 |
| **宏观映射族** | 跨市场传导 | `comex_gold_return`, `crude_return`, `usd_index` | AU, SC, IF |

### 5.2 第2层：策略模板化（Strategy Templates）

程序在模板内替换因子，而非从零搭建。3个核心模板：

**模板A：趋势跟踪**
```
signal = sign([动量族因子]) × [波动率族因子作为仓位系数] × [期限结构族确认]
entry = signal > threshold AND [持仓量族确认趋势有资金跟进]
exit = ts_return_since_entry < -stop_loss OR [均值回归族显示超买]
```

**模板B：波段反转**
```
signal = -sign([均值回归族因子]) × (1 - [趋势族强度])
entry = abs([均值回归族因子]) > extreme_threshold AND [价量族显示缩量]
exit = [均值回归族因子]回归至0 OR holding_time > max_bars
```

**模板C：期限结构套利**
```
signal = sign([期限结构族因子]) × [宏观映射族方向确认]
entry = abs([期限结构族因子]) > contango_threshold
exit = [期限结构族因子]衰减至50% OR 换月前5天
```

**进化规则**：60%个体基于模板变异，40%完全自由组合。

### 5.3 第3层：种子初始化（Seeded Evolution）

预置经典种子，第1-10代强制保留20%种子个体，新个体必须击败至少一个种子才能进入Deployable池。

| 种子ID | 族组合 | 表达式 | 来源 |
|--------|--------|--------|------|
| S01 | 动量+持仓量 | `cs_rank(ts_return(close,20)) × cs_rank(oi_change)` | 经典动量+资金确认 |
| S02 | 均值回归+波动率 | `zscore(close,20) × (1 - vol_regime)` | 布林带思想 |
| S03 | 期限结构+宏观 | `basis × sign(comex_gold_return)` | 基差+外盘联动 |
| S04 | 价量+微观结构 | `ts_corr(close,volume,10) × night_gap_filter` | 跳空放量确认 |

### 5.4 第4层：语义约束（Semantic Constraints）

硬拦截无意义/危险表达式：
- 禁止 `close / volume`（量能为0时崩溃，无量纲混乱）
- 禁止 `log(负数)` 或 `sqrt(负数)`
- `ts_corr` 的两个序列必须有相同量纲
- 树深度>8，适应度×0.8惩罚
- 同一族原语连续嵌套>2层，适应度×0.9惩罚
- 包含 `night_gap` 的因子，必须同时包含 `vol_regime` 或 `oi_change`
- `basis` 因子不能单独作为信号，必须配合 `trend_strength`

### 5.5 第5层：分层进化（Hierarchical Evolution）

**Stage 1：单因子挖掘** — 只进化单因子（树深<=4），筛选IC>0.03  
**Stage 2：双因子组合** — 从Stage 1 Top因子中两两跨族组合，筛选夏普>0.8  
**Stage 3：策略填充** — 将组合填入模板，进化参数，完整回测验证

### 5.6 第6层：动态方向调节（Dynamic Steering）

每周末分析各族近20日表现，自动调整下一代进化偏好：
- 若动量族近20日夏普0.3（失效），则下一代动量原语选择概率×0.5
- 若均值回归族近20日夏普1.2（有效），则概率×1.5

## 六、核心机制：进化-替换-实盘闭环

### 6.1 状态机（Candidate Lifecycle）

```
Seed → Backtest → Paper → Deployable → Running → Degraded → Retired
```

- **Seed**：刚进化出来，未经验证
- **Backtest**：通过向量化回测 + 天勤桥接验证
- **Paper**：进入模拟盘，运行至少2周
- **Deployable**：Paper表现达标，等待用户手动开启或自动替补
- **Running**：正在实盘/模拟盘运行，占用资金
- **Degraded**：表现不达标或回撤超限，淘汰
- **Retired**：彻底归档，不再参与竞争

### 6.2 策略替换规则（自动，不可人工干预）

1. 每个品种维护3个并行策略池：趋势池(4策略)、波段池(4策略)、反转池(2策略)
2. 每日收盘后评分：按近5日夏普 + 近20日Calmar综合排名
3. 替换触发：
   - Paper策略近5日夏普 > Running策略近5日夏普 × 1.2 → **自动替换**
   - Running策略近5日夏普 < 0 且回撤 > 8% → **强制降级**，次优策略顶上
   - 某Regime下无策略达标 → **空仓**

### 6.3 品种手动开关（用户刚需）

每个品种三态：DISABLED / PAPER / LIVE
- 切换LIVE需二次确认，且系统自检：
  1. 该品种当前有Deployable策略
  2. 账户保证金充足
  3. 天勤连接正常
  4. 当日未触发全系统熔断
- 关闭后该品种所有策略Pause，仓位可选"平仓"或"保持"

### 6.4 进化节奏（数据流）

```
每根1h K线 → 实时计算层（更新因子值 → 信号生成 → 下单/风控）
    ↓ 表现数据
每根K线 → 评估层（滚动夏普/回撤/Calmar计算 → 策略排名更新 → 替换判断）
    ↓ 每日收盘后
每晚20:30 → 进化层（下载最新6个月数据 → 滑动窗口进化60代 → 新候选入Seed池）
    ↓ 每周/每月
周末 → 反馈层（分析各原语族表现 → 调整下一代进化偏好）
```

**时序纪律（死守）**：
- 今晚20:30进化，只能用昨日及以前的K线（T-1截断）
- 进化窗口滑动6个月，验证用2年Walk-Forward
- 新K线来时不重新进化，只更新Running策略的因子值

## 七、数据库核心Schema

### 7.1 TimescaleDB：行情表

```sql
CREATE TABLE ohlcv_1h (
    time TIMESTAMPTZ NOT NULL,
    symbol TEXT NOT NULL,
    contract TEXT NOT NULL,
    open DOUBLE PRECISION,
    high DOUBLE PRECISION,
    low DOUBLE PRECISION,

    PRIMARY KEY (time, symbol, contract)
);
SELECT create_hypertable('ohlcv_1h', by_range('time'), if_not_exists => TRUE);
```

### 7.2 SQLite：候选策略生命周期

```sql
CREATE TABLE candidates (
    id TEXT PRIMARY KEY,
    symbol TEXT NOT NULL,
    formula TEXT NOT NULL,
    status TEXT CHECK(status IN ('SEED','BACKTEST','PAPER','DEPLOYABLE','RUNNING','DEGRADED','RETIRED')),
    regime TEXT CHECK(regime IN ('TREND','BAND','REVERSAL')),
    sharpe_train REAL,
    sharpe_val REAL,
    sharpe_test REAL,
    sharpe_paper_5d REAL,
    max_dd REAL,
    calmar REAL,
    generation INTEGER,
    parent_id TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    activated_at TIMESTAMP
);
```

### 7.3 SQLite：交易记录

```sql
CREATE TABLE trades (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    symbol TEXT,
    contract TEXT,
    candidate_id TEXT,
    direction TEXT CHECK(direction IN ('BUY','SELL')),
    offset_flag TEXT CHECK(offset_flag IN ('OPEN','CLOSE','CLOSE_TODAY')),
    price REAL,
    volume INTEGER,
    margin REAL,
    commission REAL,
    trade_time TIMESTAMP,
    pnl REAL,
    FOREIGN KEY (candidate_id) REFERENCES candidates(id)
);
```

### 7.4 SQLite：品种开关状态

```sql
CREATE TABLE symbol_switches (
    symbol TEXT PRIMARY KEY,
    mode TEXT CHECK(mode IN ('OFF','PAPER','LIVE')),
    switched_by TEXT,
    switched_at TIMESTAMP,
    reason TEXT
);
```

## 十三、关键风险提醒（开发时必须处理）

1. **主力合约换月**：期货有到期日，系统必须自动映射到下一主力，回测时用真实合约而非连续合约（避免换月跳空污染）
2. **夜盘跳空**：商品期货夜盘开盘跳空是主要噪音源，必须设计`night_gap_filter`
3. **IF平今手续费陷阱**：IF平今手续费是隔日的10倍，策略必须设计为隔日平仓或持仓过夜，系统中硬编码禁止`CLOSE_TODAY`
4. **保证金实时监控**：1.5万限额是硬约束，系统必须实时计算占用保证金，接近限额时拒绝开仓
5. **时序纪律**：进化只能用T-1及以前的数据，T日数据只用于评估，严禁未来函数
6. **断点续传**：期货有休市，进化引擎不是7×24，而是每晚20:30触发，休市时暂停，开盘前预热

### 5.1 第1层：原语族化（Primitive Families）

#### 5.1.1 八族原语详细定义

[代码位置] quant_engine/factors/registry.py

PRIMITIVE_FAMILIES 包含8个族：
- momentum: 趋势延续类因子，weight=0.20
  - ts_return(series, period): 时序收益率
  - ts_corr_ma(series, period): 价格与均线相关性
  - cs_rank_return(series, period): 截面动量排名
  - ts_slope(series, period): 价格斜率
  - ts_momentum_break(series, period): 突破近期高点距离

- mean_reversion: 均值回归类因子，weight=0.15
  - zscore(series, period): Z分数
  - rsi(series, period): RSI指标
  - distance_from_ma(series, period): 距均线距离
  - bb_position(series, period): 布林带位置
  - ts_min_max_position(series, period): 高低点区间位置

- volatility: 波动率类因子，weight=0.15
  - ts_std(series, period): 标准差
  - atr(high, low, close, period): 真实波动幅度
  - ts_range(high, low, close): 价格区间比
  - vol_regime(short, long): 波动率状态
  - realized_vol(period): 已实现波动率

- price_volume: 价量关系类因子，weight=0.15
  - ts_corr_pv(price_series, volume_series, period): 价量相关性
  - volume_zscore(period): 成交量Z分数
  - obv(): 能量潮
  - volume_price_divergence(period): 价量背离
  - money_flow(high, low, close): 资金流量

- term_structure: 期限结构类因子，weight=0.10
  - basis(spot_price, futures_price): 基差
  - roll_yield(near, far): 展期收益
  - spread_nf(near, far): 远近月价差比
  - basis_zscore(period): 基差Z分数
  - contango_ratio(near, far): 升贴水率

- open_interest: 持仓量类因子，weight=0.10
  - oi_change(period): 持仓量变化率
  - oi_price_divergence(period): 持仓量价格背离
  - oi_vol_ratio(): 持仓量成交量比
  - oi_zscore(period): 持仓量Z分数
  - oi_momentum(period): 持仓量动量

- microstructure: 微观结构类因子，weight=0.10
  - night_gap(): 夜盘跳空
  - opening_range(): 开盘区间
  - idr_ratio(period): 日内波动率比
  - night_gap_filter(): 跳空过滤
  - session_return(): 时段收益

- macro_proxy: 宏观映射类因子，weight=0.05
  - comex_gold_return(period): COMEX黄金收益
  - crude_return(period): 原油收益
  - usd_index(period): 美元指数
  - a50_return(period): A50收益
  - bond_yield_spread(): 中美利差

#### 5.1.2 族间组合规则

- 策略模板强制要求：至少2个不同族，最多4个族
- 禁止组合：momentum + mean_reversion（趋势和反转不能同时作为信号源）
- 推荐组合：
  - momentum + open_interest（动量+资金确认）
  - mean_reversion + volatility（反转+波动率过滤）
  - term_structure + macro_proxy（基差+宏观确认）
  - price_volume + microstructure（价量+盘口）

## 第六部分：核心机制 - 进化-替换-实盘闭环

### 6.1 候选状态机

状态流转：
SEED -> BACKTEST -> PAPER -> DEPLOYABLE -> RUNNING -> DEGRADED -> RETIRED

状态转换规则：
- SEED -> BACKTEST: 进化生成后自动进入
- BACKTEST -> PAPER: 向量化回测通过 + 天勤桥接通过
- BACKTEST -> DEGRADED: 回测不达标
- PAPER -> DEPLOYABLE: 模拟盘运行2周 + 夏普>0.8
- PAPER -> DEGRADED: 模拟盘夏普<0.5或回撤>10%
- DEPLOYABLE -> RUNNING: 用户手动开启 + 系统自检通过
- RUNNING -> DEGRADED: 近5日夏普<0且回撤>8%
- RUNNING -> DEPLOYABLE: 新策略挑战成功（旧策略自动降级）
- DEGRADED -> RETIRED: 归档满30天
- RUNNING -> PAUSED: 用户手动关闭

### 6.2 策略替换规则

[代码位置] quant_engine/core/candidate_core.py

自动替换触发条件：
1. Paper挑战：Paper夏普 > Running夏普 x 1.2，且Paper夏普>0.8，且Paper运行>=14天
2. 回撤超限：Running当前回撤>8%且近5日夏普<0
3. Regime不匹配：Running模板Regime != 当前Regime且连续5天未交易

### 6.3 品种手动开关

[代码位置] quant_engine/runtime/manual_switch.py

每个品种三态：OFF / PAPER / LIVE

切换到LIVE的强制自检（不可跳过）：
1. 该品种有Deployable策略
2. 账户保证金充足（可用>=所需）
3. 天勤连接正常
4. 当日未触发全系统熔断
5. 不在交割月
