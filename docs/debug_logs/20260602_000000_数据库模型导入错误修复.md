# 数据库模型导入错误修复记录

**日期**: 2026-06-02 00:00:00  
**任务**: 修复期货自动进化因子挖掘系统的ImportError异常，添加缺失的SQLAlchemy模型

## 问题描述

后端服务器启动时遇到大量ImportError异常，原因是API路由文件中引用的数据库模型在`app.models`中未定义或未导出。

## 修复内容

### 1. 添加缺失的数据库模型

#### 1.1 `app/models/trading.py`
- **OrderCost**: 交易成本记录表
- **LiveTransitionCandidate**: 实盘过渡候选表
- **OrderTypeConfig**: 订单类型配置表
- **ReplaySession**: 回放会话表
- **GeneratedReport**: 生成的报告表
- **SimulationSession**: 模拟交易会话表
- **SimulationOrder**: 模拟订单表
- **SimulationPosition**: 模拟持仓表

#### 1.2 `app/models/misc.py`
- **BacktestLiveComparison**: 回测实盘对比表
- **ABTestResult**: A/B测试结果表
- **SystemAnomaly**: 系统异常检测表
- **CorrelationMatrix**: 相关性矩阵表
- **PortfolioOptimization**: 投资组合优化表
- **MicrostructureData**: 微结构数据表
- **ArbitrageOpportunity**: 套利机会表
- **CrossMarketTrade**: 跨市场交易表
- **StrategyMonitorStatus**: 策略监控状态表
- **StrategyWeight**: 策略权重表
- **StrategySwitchHistory**: 策略切换历史表

#### 1.3 `app/models/evolution.py`
- **GenerationStats**: 世代统计表

#### 1.4 `app/models/data.py`
- **DataQualityReport**: 数据质量报告表

#### 1.5 `app/models/risk.py`
- **AlertHistory**: 告警历史表
- **CapitalAllocation**: 资金分配表
- **PortfolioMetrics**: 投资组合指标表
- **LiquidityRiskAnalysis**: 流动性风险分析表
- **PositionLimitConfig**: 持仓限制配置表
- **LiveRiskEvent**: 实盘风险事件表
- **RiskConfig**: 风险配置表

### 2. 更新模型导出

更新`app/models/__init__.py`，导入并导出所有新增模型。

### 3. 修复API路由导入错误

修复以下文件中的`get_db`到`get_session`的导入错误：
- `app/api/routes/evolution/classification.py`
- `app/api/routes/evolution/generalization.py`
- `app/api/routes/evolution/joint_evolution.py`

### 4. 修复SQL语法错误

修复`app/models/generalization.py`中的SQL语法错误：
- 将`server_default=func.false()`改为`server_default=text('false')`
- 添加`text`导入

### 5. 修复TQSDK交易引擎

修复`quant_engine/ops/tqsdk_trading.py`中的账户信息获取：
- 使用`getattr`安全获取账户属性，避免AttributeError

### 6. 添加数据库缺失字段

为`candidates`表添加缺失字段：
```sql
ALTER TABLE candidates ADD COLUMN IF NOT EXISTS is_universal BOOLEAN DEFAULT false;
ALTER TABLE candidates ADD COLUMN IF NOT EXISTS generalization_score FLOAT;
ALTER TABLE candidates ADD COLUMN IF NOT EXISTS applicable_symbols TEXT;
ALTER TABLE candidates ADD COLUMN IF NOT EXISTS generalization_tested_at TIMESTAMP WITH TIME ZONE;
ALTER TABLE candidates ADD COLUMN IF NOT EXISTS is_selected_strategy BOOLEAN DEFAULT false;
ALTER TABLE candidates ADD COLUMN IF NOT EXISTS strategy_rank INTEGER;
```
