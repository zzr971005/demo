### 1. 后端API开发

**文件位置**: `backend/app/api/baseline_comparison.py`

**API端点**:
- `GET /baseline/comparison/{symbol}` - 获取策略与基线对比数据
- `GET /baseline/strategies` - 获取可用基线策略列表
- `GET /baseline/summary/{symbol}` - 获取对比摘要

**基线策略**:
1. **buy_and_hold** - 买入持有
2. **sma_crossover** - 双均线交叉
3. **momentum** - 动量策略
4. **mean_reversion** - 均值回归

**数据模型**:
```typescript
// 对比指标
interface MetricData {
  name: string
  strategy_value: number
  baseline_value: number
  improvement: number
  unit: string
  is_better: boolean
}

// 权益点
interface EquityPoint {
  date: string
  strategy_equity: number
  baseline_equity: number
}

// 月度收益
interface MonthlyReturn {
  month: string
  strategy_return: number
  baseline_return: number
}

// 回撤点
interface DrawdownPoint {
  date: string
  strategy_drawdown: number
  baseline_drawdown: number
}

// 完整对比数据
interface BaselineComparison {
  symbol: string
  baseline_name: string
  time_period: string
  metrics: MetricData[]
  equity_curve: EquityPoint[]
  monthly_returns: MonthlyReturn[]
  drawdown_curve: DrawdownPoint[]
  win_rate_comparison: {
    long_win_rate: number
    short_win_rate: number
    baseline_win_rate: number
  }
  trade_analysis: {
    total_trades: number
    winning_trades: number
    losing_trades: number
    avg_win: number
    avg_loss: number
    max_win: number
    max_loss: number
    consecutive_wins: number
    consecutive_losses: number
  }
}
```

## UI优化记录 (2026-05-31)

### 暗色模式下图表线条颜色显示问题修复

**问题描述**:
在暗色模式下，基线对比页面的权益曲线图表中，所有策略线条都显示为灰色，无法区分不同策略。

**根本原因**:
在 `frontend/src/index.css` 中存在全局CSS规则，使用 `!important` 强制覆盖了所有SVG线条的颜色：

```css
.dark svg line {
  stroke: oklch(0.35 0.02 240) !important;  /* 灰色 */
}

.dark svg path {
  stroke: oklch(0.78 0.02 240) !important;  /* 灰色 */
}
```

这些规则会覆盖图表组件中设置的线条颜色属性。

**解决方案**:
移除了对SVG线条的全局颜色覆盖规则，只保留对SVG文字的颜色设置：

```css
/* SVG 图表在深色模式下的文字颜色 */
.dark svg {
  color: oklch(0.78 0.02 240) !important;
}

.dark svg text {
  fill: oklch(0.78 0.02 240) !important;
}

/* 移除对SVG线条的全局颜色覆盖，避免影响图表线条颜色 */
```

**图表颜色配置**:
- 策略: `#60a5fa` (明亮蓝色)
- 买入持有: `#a78bfa` (紫色)
- 双均线交叉: `#34d399` (明亮绿色)
- 动量策略: `#fbbf24` (明亮黄色)
- 均值回归: `#f472b6` (明亮粉色)

**相关文件**:
- `frontend/src/index.css` - 移除SVG线条全局颜色覆盖
- `frontend/src/pages/BaselineComparison.tsx` - 使用LineChart替代AreaChart，配置明亮颜色
