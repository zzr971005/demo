## 一、参考系统分析（网友开发记录）

### 1.1 参考系统功能架构

根据图片分析，参考系统是一个**加密货币量化策略挖掘系统**，具有以下特点：

#### 侧边导航栏 (7个主模块)
```
├─ Demo (实时运行状态)
├─ 验证流程 (策略验证流水线)
├─ 系统架构 (模块分层展示)
├─ 研究运维 (策略研究与监控)
├─ Regime (市场状态识别)
├─ 数据资产 (数据管理)
├─ 回测 (历史回测)
└─ 配置 (系统设置)
```

#### Demo页面核心组件
1. **策略列表** - 显示各品种当前信号 (SELL/HOLD)、分数、Edge值
2. **信号详情面板** - 选中品种后显示：
   - 信号方向 (SELL)
   - 分数 (-0.2578)
   - 置信度 (1.000)
   - p↑/p↓ 概率
   - Edge值
   - Breadth/Edge/Risk/macd_hist 指标
3. **持仓面板** - 当前仓位、开仓时间、盈亏
4. **交易记录** - 时间、类型、方向、价格、仓位、理由
5. **研究基线** - PF、收益、回撤、交易次数、月胜率、N_eff

#### 验证流程页面
- 显示最近周期分阶段卡点
- 包含：Cycle、状态、Search接收/评估、Light refine、Replay、Validation、Demo入队
- 每个周期显示：drop率、max_validation_drawdown、research_max_drawdown、profit_factor

#### 系统架构页面
- 主产线流程：挖掘 → 搜索 → 验证 → 调优 → Demo → 反馈回灌
- 技术栈概览
- 数据流向图
- 模块分层 (数据层/因子层/搜索与进化层/验证层/候选管理层/Regime层/执行层/基础设施层)

### 6.2 验证流程状态机

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  Search │───►│  Replay │───►│Validate │───►│  Demo   │───►│Feedback │
│  搜索   │    │  重放   │    │  验证   │    │  模拟   │    │  反馈   │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
     │              │              │              │              │
     ▼              ▼              ▼              ▼              ▼
  completed    completed      completed      completed      completed
  degraded     degraded       degraded       degraded       degraded
```

### 6.3 研究基线指标计算

```python
# PF (Profit Factor)
PF = 总盈利 / 总亏损

# 收益 (Return)
Return = (期末权益 - 期初权益) / 期初权益 * 100%

# 回撤 (Drawdown)
MaxDrawdown = 最大峰值到谷底跌幅

# 月胜率 (Monthly Win Rate)
MonthlyWinRate = 盈利月数 / 总月数 * 100%

# N_eff (Effective Number of Trades)
N_eff = 实际交易次数 / 理论最大交易次数
```

## 八、数据库表补充

### 8.1 新增表

```sql
-- 进化周期表
CREATE TABLE evolution_cycles (
    id SERIAL PRIMARY KEY,
    cycle_number INTEGER NOT NULL,
    status VARCHAR(20) NOT NULL, -- running/completed/degraded
    stage VARCHAR(20) NOT NULL, -- search/replay/validation/demo/feedback
    search_received INTEGER,
    search_dropped INTEGER,
    light_refine_input INTEGER,
    light_refine_output INTEGER,
    replay_passed INTEGER,
    replay_failed INTEGER,
    validation_passed INTEGER,
    validation_failed INTEGER,
    demo_queued INTEGER,
    started_at TIMESTAMP,
    completed_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 实时信号表
CREATE TABLE realtime_signals (
    id SERIAL PRIMARY KEY,
    symbol VARCHAR(10) NOT NULL,
    direction VARCHAR(10) NOT NULL, -- LONG/SHORT/FLAT
    score DECIMAL(10,4),
    confidence DECIMAL(5,4),
    edge DECIMAL(10,4),
    p_up DECIMAL(5,4),
    p_down DECIMAL(5,4),
    breadth DECIMAL(10,4),
    risk DECIMAL(10,4),
    macd_hist DECIMAL(10,4),
    generated_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 研究基线表
CREATE TABLE research_baselines (
    id SERIAL PRIMARY KEY,
    candidate_id VARCHAR(50) NOT NULL,
    pf DECIMAL(10,4),
    return_pct DECIMAL(10,4),
    max_drawdown_pct DECIMAL(10,4),
    total_trades INTEGER,
    monthly_win_rate DECIMAL(5,4),
    n_eff DECIMAL(10,4),
    period_start DATE,
    period_end DATE,
    created_at TIMESTAMP DEFAULT NOW()
);

-- Regime状态表
CREATE TABLE regime_states (
    id SERIAL PRIMARY KEY,
    symbol VARCHAR(10) NOT NULL,
    regime VARCHAR(20) NOT NULL, -- trend/oscillation/breakout
    confidence DECIMAL(5,4),
    features JSONB,
    started_at TIMESTAMP,
    ended_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 用户设置表
CREATE TABLE user_settings (
    id SERIAL PRIMARY KEY,
    user_id VARCHAR(50) NOT NULL,
    theme VARCHAR(10) DEFAULT 'light',
    notifications_enabled BOOLEAN DEFAULT TRUE,
    alert_thresholds JSONB,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```
