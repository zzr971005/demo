## 使用指南

### 开发人员

1. **查看当前需求**: 阅读 `v1.0-working.md`
2. **了解已实现功能**: 查看 v1.0-working.md 的"与当前项目状态对比"章节
3. **领取开发任务**: 查看 v1.0-working.md 的"待开发功能详细计划"章节
4. **完成任务后**: 更新 v1.0-working.md 中的状态，并在 CHANGELOG.md 记录

### 项目经理

1. **查看整体进度**: 查看 v1.0-working.md 的进度可视化
2. **了解变更历史**: 查看 CHANGELOG.md
3. **追溯原始需求**: 查看 v1.0-archived.md

## 版本管理规则

### 版本命名

```
v{主版本}.{次版本}-{状态}

状态说明:
- archived: 存档版本，只读
- working: 工作副本，可编辑
- final: 最终版本，阶段性完成
- draft: 草稿版本，未评审
```

### 变更流程

1. 修改 `v1.0-working.md` 前，先在 `CHANGELOG.md` 记录变更计划
2. 完成修改后，在 `CHANGELOG.md` 记录实际变更
3. 如需发布新版本：
   - 将 `v1.0-working.md` 复制为 `v1.0-final.md`
   - 或创建 `v1.1-working.md` 开始新版本
