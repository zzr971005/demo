## 待开发功能详细计划

### P0 - 核心缺失（阻塞实盘）

#### 1. 验证流程监控页面
**规格书章节**: 第9章 8.2  
**功能描述**: 显示进化周期流水线状态，包括Search→Replay→Validation→Demo各阶段卡点  
**验收标准**:
- [ ] 显示当前进化周期和各阶段状态
- [ ] 显示每个阶段的输入/输出数量
- [ ] 显示drop率和失败原因
- [ ] 支持点击查看周期详情

**开发计划**:
- 后端API: `GET /api/evolution/cycles`, `GET /api/evolution/cycles/{id}`
- 前端页面: `/validation` 路由
- 预计工时: 1-2天

#### 2. 实时信号生成逻辑
**规格书章节**: 第5章 5.3  
**功能描述**: 将实时因子值转换为交易信号（多/空/平）  
**验收标准**:
- [ ] 根据因子值生成信号方向
- [ ] 计算信号强度（分数）
- [ ] 计算置信度和Edge值
- [ ] 支持Regime过滤

**开发计划**:
- 后端: 扩展 `realtime_factor_engine.py` 添加信号生成
- 前端: 在SymbolDetail显示实时信号
- 预计工时: 1-2天

#### 3. 研究基线对比
**规格书章节**: 第9章 8.3  
**功能描述**: 显示PF、收益、回撤、胜率、N_eff等指标对比  
**验收标准**:

- [ ] 支持时间范围选择
- [ ] 支持品种筛选
- [ ] 可视化对比图表

**开发计划**:

- 预计工时: 2-3天

#### 4. Regime状态识别引擎
