# 基线对比功能文档

## 功能概述

基线对比功能用于将进化因子策略与经典基线策略进行绩效对比，评估策略的实际价值。该功能支持单品种对比和多品种横向对比，提供全面的绩效指标分析和可视化图表。

## 基线策略

系统支持4种经典基线策略：

### 1. 买入持有 (Buy and Hold)
- **策略逻辑**: 在期初买入并持有至期末，不进行任何交易
- **适用场景**: 作为最简单的基准，衡量被动投资收益
- **计算方式**: 
  - 持仓: 全程满仓 (position = 1)
  - 收益: (期末价格 - 期初价格) / 期初价格

### 2. 双均线交叉 (SMA Crossover)
- **策略逻辑**: 短期均线上穿长期均线时买入，下穿时卖出
- **参数**: 短期均线=10期，长期均线=30期
- **适用场景**: 趋势跟踪策略基准
- **计算方式**:
  ```python
  short_ma = SMA(close, 10)
  long_ma = SMA(close, 30)
  signal = crossover(short_ma, long_ma)
  ```

### 3. 动量策略 (Momentum)
- **策略逻辑**: 基于20日动量，动量>2%做多，<-2%做空
- **适用场景**: 动量因子基准
- **计算方式**:
  ```python
  momentum = (close - close[20]) / close[20]
  if momentum > 0.02: position = 1
  elif momentum < -0.02: position = -1
  ```

### 4. 均值回归 (Mean Reversion)
- **策略逻辑**: 基于20日Z-score，Z-score>1做空，<-1做多
- **适用场景**: 均值回归策略基准
- **计算方式**:
  ```python
  zscore = (close - SMA(close, 20)) / STD(close, 20)
  if zscore > 1.0: position = -1
  elif zscore < -1.0: position = 1
  ```

## 对比指标

### 核心绩效指标
1. **总收益率**: 策略与基线的累计收益对比
2. **年化收益率**: 标准化为年化收益
3. **夏普比率**: 风险调整后收益 (Sharpe Ratio)
4. **最大回撤**: 最大亏损幅度 (Max Drawdown)
5. **卡玛比率**: 年化收益/最大回撤 (Calmar Ratio)
6. **胜率**: 盈利交易占比 (Win Rate)
7. **盈亏比**: 平均盈利/平均亏损
8. **交易次数**: 总交易频次
9. **波动率**: 收益率标准差

### 可视化图表
1. **权益曲线对比**: 策略与基线的资金曲线
2. **回撤曲线对比**: 策略与基线的回撤情况
3. **月度收益对比**: 各月收益表现
4. **交易分析**: 盈亏分布、连续盈亏等

## 数据持久化

### 数据表结构

#### baseline_comparison_results 表
存储预计算的基线对比结果，用于快速展示和横向对比。

```python
class BaselineComparisonResult(Base):
    __tablename__ = "baseline_comparison_results"
    
    id: int
    symbol: str                    # 品种代码
    baseline_type: str             # 基线策略类型
    strategy_candidate_id: str     # 策略因子ID (外键)
    period_start: datetime         # 回测开始时间
    period_end: datetime           # 回测结束时间
    
    # 策略指标
    strategy_return: float
    strategy_sharpe: float
    strategy_max_drawdown: float
    strategy_calmar: float
    strategy_win_rate: float
    strategy_total_trades: int
    
    # 基线指标
    baseline_return: float
    baseline_sharpe: float
    baseline_max_drawdown: float
    
    # JSON数据
    equity_curve_json: str         # 权益曲线数据
    monthly_returns_json: str      # 月度收益数据
    drawdown_curve_json: str       # 回撤曲线数据
    
    computed_at: datetime          # 计算时间
```

### 数据来源

1. **OHLCV数据**: 从 `OHLCV1H` 表获取1小时K线数据
2. **候选因子**: 从 `candidates` 表获取可部署的策略因子
3. **计算结果**: 实时计算并持久化到 `baseline_comparison_results` 表

## API接口

### 1. 获取基线策略列表
```
GET /api/baseline/strategies
```
返回所有可用的基线策略。

### 2. 获取单品种对比
```
GET /api/baseline/comparison/{symbol}?baseline={baseline_type}
```
参数:
- `symbol`: 品种代码 (如 RB, I, J)
- `baseline`: 基线策略类型 (buy_and_hold, sma_crossover, momentum, mean_reversion)

返回完整的对比数据，包括指标、权益曲线、月度收益等。

### 3. 获取对比摘要
```
GET /api/baseline/summary/{symbol}
```
返回该品种的对比摘要，用于快速概览。

### 4. 获取所有品种横向对比
```
GET /api/baseline/all-symbols?baseline={baseline_type}
```
返回所有品种的横向对比数据，用于多品种分析。

### 5. 刷新预计算结果
```
POST /api/baseline/refresh
```
后台任务，重新计算并持久化所有品种的基线对比结果。

## 计算逻辑

### 策略选择
- 自动选择该品种 sharpe_test 最高的 DEPLOYABLE 或 RUNNING 状态因子
- 如果没有可部署因子，则使用基线策略作为策略数据

### 回测参数
- **初始资金**: 1,000,000 元
- **回测周期**: 最近1年 (365天)
- **数据频率**: 1小时K线
- **最小数据量**: 50条K线
- **杠杆倍数**: 10倍（期货默认杠杆）
- **保证金比例**: 10%（期货默认保证金）

### 期货杠杆计算
回测考虑了期货的杠杆特性：
- **杠杆收益**: 价格涨跌幅 × 杠杆倍数
- **爆仓检测**: 当权益 ≤ 0 时判定为爆仓，权益归零
- **保证金**: 使用10%保证金，可开仓价值 = 初始资金 / 保证金比例

### 指标计算
```python
# 杠杆收益计算
price_return = (exit_price - entry_price) / entry_price
leveraged_return = price_return * leverage  # 10倍杠杆

# 爆仓检测
if equity[i] <= 0:
    equity[i:] = 0  # 爆仓后权益归零
    break

# 夏普比率
sharpe = (mean_return - risk_free_rate) / std_return
# 年化处理
annual_return = mean_return * 252
annual_std = std_return * sqrt(252)
sharpe = (annual_return - 0.03) / annual_std

# 最大回撤
peak = equity[0]
max_dd = 0
for i in range(1, len(equity)):
    if equity[i] > peak:
        peak = equity[i]
    dd = (peak - equity[i]) / peak
    max_dd = max(max_dd, dd)

# 卡玛比率
calmar = annual_return / max_dd
```

## 使用场景

1. **策略评估**: 评估进化因子是否优于经典策略
2. **基准设定**: 为实盘交易设定合理的绩效基准
3. **策略选择**: 在多个候选因子中选择相对基线表现最好的
4. **风险控制**: 识别过度拟合的因子 (对比基线无明显优势)

## 注意事项

1. **数据完整性**: 确保OHLCV数据充足 (至少50条K线)
2. **因子状态**: 只有 DEPLOYABLE 或 RUNNING 状态的因子才会被选中
3. **回测偏差**: 基线策略使用简单规则，可能与实际交易有偏差
4. **数据时效性**: 预计算结果需要定期刷新以保持准确性
5. **品种差异**: 不同品种的基线表现差异较大，需结合品种特性分析

### 数据流
```
OHLCV1H (TimescaleDB) 
  → get_ohlcv_data() 
  → run_baseline_backtest() 
  → compute_baseline_comparison() 
  → BaselineComparisonResult (PostgreSQL)
  → API响应 
  → 前端展示
```

## 维护建议

1. **定期刷新**: 建议每天调用 `/api/baseline/refresh` 刷新预计算结果
2. **数据监控**: 监控OHLCV数据完整性，避免数据缺失导致计算失败
3. **性能优化**: 对于多品种横向对比，建议使用预计算结果而非实时计算
4. **错误处理**: 当数据不足时，前端应显示友好的提示信息
