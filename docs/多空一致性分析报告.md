## 一致性检查

### ✅ 已一致的环节

1. **回测引擎**：engine.py 和 tq_bridge.py 使用相同的信号逻辑
2. **参数传递**：所有环节使用相同的参数结构

1. **参数演化**：进化过程中可能优化阈值参数
2. **策略部署**：实盘可能使用不同参数
3. **数据差异**：实盘数据与历史数据可能存在差异

## 改进建议

### 1. 增加信号验证机制

```python
def validate_signal_consistency(factor_value: float, signal: int, 
                               upper_threshold: float, lower_threshold: float) -> bool:
    """验证信号生成的一致性"""
    expected_signal = 0
    if factor_value > upper_threshold:
        expected_signal = 1
    elif factor_value < lower_threshold:
        expected_signal = -1
    
    return signal == expected_signal
```

### 2. 统一参数管理

```python
@dataclass
class TradingSignalConfig:
    """交易信号配置"""
    upper_threshold: float = 0.5
    lower_threshold: float = -0.5
    direction_mode: int = 0
    
    def generate_signal(self, factor_value: float) -> int:
        """生成交易信号"""
        if factor_value > self.upper_threshold:
            signal = 1
        elif factor_value < self.lower_threshold:
            signal = -1
        else:
            signal = 0
            
        # 方向模式过滤
        if self.direction_mode == 1 and signal < 0:
            return 0
        elif self.direction_mode == -1 and signal > 0:
            return 0
        return signal
```
