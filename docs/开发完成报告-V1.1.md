## 🔍 新增功能详情

### 1. 持续进化引擎（永不停止模式）

**核心文件**:
- `backend/quant_engine/ops/gpu_evolution.py` - GPU加速进化引擎
- `backend/quant_engine/ops/continuous_evolution_center.py` - 持续进化中心

**核心特性**:

| 特性 | 说明 |
|------|------|
| **永不停止** | `max_stagnation=0` 禁用停滞检查，持续进化 |
| **暖启动** | 支持从检查点恢复，断点续跑 |
| **因子库自动更新** | 每50代自动更新因子库 |
| **自适应参数** | 根据种群多样性动态调整参数 |
| **检查点保存** | 每100代自动保存检查点 |

**持续进化配置**:
```python
# 默认配置
population_size: int = 500       # 种群大小
max_generations: int = 1000      # 最大代数（可设为0无限运行）
max_stagnation: int = 0          # 0 = 永不停止
crossover_rate: float = 0.8      # 交叉率
mutation_rate: float = 0.2       # 变异率
elite_size: int = 10             # 精英保留数
checkpoint_interval: int = 100   # 检查点间隔
factor_library_update_interval: int = 50  # 因子库更新间隔
```

**进化流程图**:
```
┌─────────────────────────────────────────────────────────────┐
│                    持续进化主循环                            │
├─────────────────────────────────────────────────────────────┤
│  [初始化种群] → [评估适应度] → [选择最优] → [交叉变异]        │
│       ↑                                              │     │
│       └─────────── [检查点保存] ← [因子库更新] ←───────┘     │
│                                                              │
│  * max_stagnation=0 → 无终止条件，持续运行                    │
│  * 支持手动停止和断点续跑                                    │
└─────────────────────────────────────────────────────────────┘
```

### 2. GPU加速模块（RTX 5070 Ti Blackwell架构）

**核心文件**:
- `backend/quant_engine/ops/gpu_evolution.py` - GPU进化引擎
- `backend/pyproject.toml` - 依赖配置

**支持架构**:
- RTX 5070 Ti (Blackwell) - sm_120
- 需要 PyTorch Nightly 2.8+ 版本

**环境配置**:

| 配置项 | 值 |
|--------|-----|
| CUDA版本 | 12.8 或 13.0 |
| PyTorch | Nightly 2.8+ |
| 驱动版本 | 575+ 或 59x 系列 |
| 计算能力 | sm_120 (Blackwell) |

**安装命令**:
```bash
# CUDA 12.8（推荐）
pip install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/cu128

# CUDA 13.0（需更新驱动）
pip install --pre torch torchvision --index-url https://download.pytorch.org/whl/nightly/cu130
```

**Poetry配置**:
```toml
[tool.poetry.dependencies]
torch = {url = "https://download.pytorch.org/whl/nightly/cu128/torch-2.8.0.dev20250520+cu128-cp311-cp311-win_amd64.whl", optional = true}
torchvision = {url = "https://download.pytorch.org/whl/nightly/cu128/torchvision-0.23.0.dev20250520+cu128-cp311-cp311-win_amd64.whl", optional = true}
torchaudio = {url = "https://download.pytorch.org/whl/nightly/cu128/torchaudio-2.2.0.dev20250520+cu128-cp311-cp311-win_amd64.whl", optional = true}

[tool.poetry.extras]
gpu = ["torch", "torchvision", "torchaudio"]
full = ["tqsdk", "torch", "torchvision", "torchaudio"]
```

**验证脚本**:
```python
import torch
print(torch.__version__)           # 应显示 dev/nightly 版本
print(torch.cuda.is_available())   # 应返回 True
print(torch.cuda.get_device_name(0))  # 应显示 RTX 5070 Ti
print(torch.cuda.get_arch_list())  # 必须包含 'sm_120'
```

**性能提升**:
- 种群级并行：同时评估多个个体
- 数据级并行：同时处理多个时间点
- 批量处理：默认 batch_size=64

### 4. Regime 状态识别引擎

**核心文件**:
- `backend/quant_engine/ops/regime_features.py` - Regime 特征计算
- `backend/quant_engine/ops/regime_engine.py` - Regime 状态引擎

**主要功能**:
- 基于 ADX (Average Directional Index) 识别市场趋势强度
- 基于布林带价格位置识别突破状态
- 动量特征计算
- 3 种核心市场状态：
  - 上升趋势（Trend Up）
  - 下降趋势（Trend Down）
  - 震荡区间（Range）
  - 突破状态（Breakout）
- 状态转换置信度计算
- 回调机制支持

**关键指标**:
- ADX 阈值：> 25 为强趋势
- 趋势方向判断：+DI / -DI 交叉
- 波动率归一化处理

### 2. 实时信号生成逻辑

**核心文件**:
- `backend/quant_engine/ops/signal_generator.py` - 信号生成器

**主要功能**:
- Z-score 标准化因子值（50周期滑动窗口）
- 信号方向判断：LONG / SHORT / NEUTRAL
- 信号强度分级：STRONG / MODERATE / WEAK / NONE
- Regime 过滤机制：
  - 趋势因子只在趋势市场触发
  - 均值回归因子只在震荡市场触发
- 信号置信度计算（0-1）
- 历史信号缓存和回调机制

**阈值配置**:
- 做多阈值：Z-score > 1.5
- 做空阈值：Z-score < -1.5
- 强信号阈值：|Z-score| > 2.5
