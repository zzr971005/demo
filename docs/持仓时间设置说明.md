# 期货因子挖掘持仓时间设置说明

## 背景

在因子挖掘中，设置固定的持仓时间比"一直持有到最后"更科学，可以避免：
- 时间偏差（长期持有可能只是市场整体上涨）
- 风险累积（长期持仓暴露更多市场风险）
- 因子失效（因子信号可能短期内有效，长期失效）

## 1H K线持仓时间分析

### 市场特征
- **期货品种**：高杠杆、高波动
- **1H K线**：中等时间尺度，平衡了噪音和趋势
- **交易成本**：手续费、滑点需要考虑

### 持仓时间选项

| 持仓时间 | K线数 | 天数 | 适用场景 | 优缺点 |
|---------|-------|------|----------|--------|
| 24小时 | 24根 | 1天 | 超短线交易 | ✓交易频率高<br>✗可能错过持续趋势 |
| 120小时 | 120根 | 5天 | **1H推荐** | ✓基于时间尺度换算<br>✓适合高频因子<br>✓平衡风险收益 |
| 168小时 | 168根 | 7天 | 短期持仓 | ✓捕捉短期趋势<br>✗交易成本较高 |
| 720小时 | 720根 | 30天 | 日线推荐 | ✓基于时间序列动量研究<br>✗不适合1H数据 |

## 基于时间尺度的持仓时间优化

### 关键认识：时间尺度差异

**重要发现**：学术研究的1个月持仓期是基于**日线数据**的，对于1小时K线需要调整！

#### 时间尺度换算原理
- **日线研究**：1个月 ≈ 22个交易日
- **1小时K线**：1天 = 24根K线
- **因子衰减**：高频因子效应衰减更快

#### 换算公式
基于市场微观结构理论：
```
1H持仓时间 = 日线持仓时间 / √24
1个月（22天）→ 22/√24 ≈ 4.5天
```

### 推荐方案：5天固定持仓（1H K线）

### 选择理由

1. **时间尺度匹配**
   - 1H K线的120根K线 = 5天
   - 适合高频因子的特性
   - 避免因子效应过度衰减

2. **学术依据调整**
   - 基于时间序列动量研究的时间尺度换算
   - 考虑1H数据的噪音和短期波动
   - 平衡因子持续性和时效性

3. **风险控制**
   - 5天持仓控制风险暴露
   - 避免长期持有的不确定性
   - 适合期货高波动特性

4. **因子有效性**
   - 给1H因子信号5天发挥作用
   - 避免短期噪音干扰
   - 捕捉中期趋势

5. **交易成本考虑**
   - 合理的交易频率（5天调仓）
   - 降低交易成本对收益的影响
   - 适合实际交易环境

### 实施细节

```python
DEFAULT_BACKTEST_PARAMS = {
    "max_holding_bars": 120,  # 120根1H K线 = 5天，基于时间尺度换算
    # ... 其他参数
}
```

### 强制平仓逻辑

```python
# 在回测引擎中
holding_bars = i - pos_entry_bar if pos != 0 else 0
time_exit = (max_holding_bars > 0 and holding_bars >= max_holding_bars)

if time_exit:
    # 强制平仓
    close_position()
```

## 不同品种的调整建议

### 高波动品种（如RB、I）
- 建议：24-48小时
- 原因：波动大，快速止盈止损

### 低波动品种（如AU、CU）
- 建议：48-72小时
- 原因：趋势相对稳定，可适当延长

### 农产品（如M、Y）
- 建议：48小时
- 原因：季节性明显，中等持仓

## 参数优化建议

可以在因子挖掘时将持仓时间作为可调参数：

```python
PARAM_GRID = {
    "max_holding_bars": [24, 48, 72],  # 可选持仓时间
    # ... 其他参数
}
```

## 注意事项

1. **数据质量**：确保1H数据连续无缺失
2. **手续费**：不同持仓时间影响交易频率
3. **滑点**：实际交易可能需要更大滑点
4. **市场环境**：牛市/熊市可能需要调整
