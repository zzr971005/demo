# 收益率计算级别和持仓周期分析

## 核心参数确认

### 1. 收益率计算级别

#### 当前设置
```python
periods_per_year: float = 252 * 5  # 1H 数据，每天约5根有效K线
```

#### 计算逻辑
```python
# 收益率计算（每根K线的收益率）
returns[i - 1] = (equity[i] - equity[i - 1]) / equity[i - 1]

# 年化收益率计算
annual_return = mean_ret * periods_per_year
annual_excess_ret = mean_ret * periods_per_year - risk_free_rate
annual_std = std_ret * np.sqrt(periods_per_year)
```

#### 分析结论
- **计算级别**：1小时K线级别
- **年化基准**：252个交易日 × 5根有效1H K线 = 1260根K线/年
- **收益率频率**：每小时计算一次收益率
- **年化方法**：简单年化（均值 × periods_per_year）

## 详细分析

### 1. 收益率计算的时间尺度

#### 数据频率
- **原始数据**：1小时K线（1H）
- **收益率计算**：每根K线计算一次
- **时间间隔**：1小时

#### 年化参数合理性
```python
periods_per_year = 252 * 5 = 1260
```

**合理性分析**：
- ✅ 考虑了交易时间（排除夜间）
- ✅ 符合期货市场实际交易时间
- ✅ 避免了24小时连续计算的偏差

**其他可能的设置**：
- `365 * 24 = 8760`：连续24小时计算（不适合期货）
- `252 * 24 = 6048`：包含夜间（不适合期货）

### 2. 持仓周期与收益计算的匹配

#### 时间尺度一致性
- **信号生成**：1小时K线
- **收益率计算**：1小时级别
- **持仓周期**：4小时（4个信号周期）

#### 合理性评估
- ✅ **时间尺度匹配**：持仓周期是信号周期的整数倍
- ✅ **专家建议符合**：符合豆包建议的2-6小时范围
- ✅ **避免过短**：4小时避免了1小时内的噪声
- ✅ **避免过长**：4小时不会导致1H因子失效

### 3. 不同持仓周期的对比

#### 原始设置（已废弃）

**问题**：

- ❌ 不符合专家建议

#### 当前设置（推荐）
```python

```

**优势**：
- ✅ 时间尺度匹配
- ✅ 符合专家建议
- ✅ 避免过拟合
- ✅ 更好的资金周转

### 4. 收益率指标的计算

#### 夏普比率
```python
annual_excess_ret = mean_ret * periods_per_year - risk_free_rate
```

#### Calmar比率
```python

```

#### 总收益率
```python
total_return = (equity[-1] - equity[0]) / equity[0]
```

### 5. 参数对结果的影响

#### periods_per_year的影响
- **数值越大**：年化收益率越高，夏普比率可能变化
- **数值越小**：年化收益率越低，可能低估策略表现
- **当前设置1260**：符合期货实际交易时间

#### max_holding_bars的影响
- **数值过小（<2）**：交易频繁，成本高，可能受噪声影响
- **数值过大（>24）**：交易稀少，可能错过信号，资金利用率低
- **当前设置4**：平衡了交易频率和信号有效性
