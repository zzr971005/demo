def run_evolution(self):
    # 1. 初始化种群
    population = self._initialize_population()
    
    # 2. 进化循环
    for generation in range(max_generations):
        # 2.1 适应度评估
        fitness_results = self._evaluate_population(population)
        
        # 2.2 选择
        selected = self._selection(population, fitness_results)
        
        # 2.3 交叉和变异

## 3. 前端监控验证四层过滤逻辑

### 3.1 四层过滤架构

#### 过滤层级
1. **Search（搜索）**: 因子表达式生成和去重
2. **Replay（回放）**: 历史数据回测验证
3. **Validation（验证）**: 过拟合检验
4. **Demo（演示）**: 最终筛选保留

#### 数据流（2026-05-31 更新）
```
Search Input: 累计所有代的search_input (累计生成的表达式总数)
    ↓
Search Output: 累计所有代的search_output (累计去重后的表达式数)
    ↓
Replay Input: 累计所有代的replay_input (累计进入Replay的表达式数)
    ↓
Replay Output: 累计所有代的replay_output (累计通过回测的因子数)
    ↓
Validation Input: 累计所有代的validation_input (累计进入Validation的因子数)
    ↓
Validation Output: 累计所有代的validation_output (累计通过过拟合检验的因子数)
    ↓
Demo Input: 累计所有代的demo_input (累计进入Demo的因子数)
    ↓
Demo Output: 累计所有代的demo_output (累计最终保留的因子数)
```

**核心原则**：所有阶段的输入和输出都是累计值，反映从进化开始至今的总和
