# 警醒：模拟数据进化事故报告

> 日期：2026-05-29  
> 性质：**数据配置失误导致的无效进化**  
> 影响：**所有历史进化产物不可信，已全量清空**

---

## 一、事故经过

用户在前端观察到进化结果出现以下异常指标，要求排查：

- 收益率：`10000%`（total_return = 100.0）
- 夏普比率：稳定在 `1.068`
- 进化速度：`50 代 / 1.84 秒`

经调查，发现这些异常不是因为策略天才，而是因为**进化引擎根本没有连接真实数据库**。

---

## 二、根因分析

### 直接原因

持续进化脚本 `backend/scripts/run_continuous_evolution.py` 在创建 `EvolutionCenter` 时**未传入 `data_hub`**：

```python
# run_continuous_evolution.py:95
# ❌ 错误代码
 center = EvolutionCenter(config)   # 没有 data_hub
```

而 `evolution_center.py` 的 `load_data()` 方法在 `data_hub` 为 `None` 时会**回退到模拟随机数据**：

```python
# evolution_center.py:277-282
if self.data_hub is not None:
    # 从数据库加载真实数据...
else:
    # 生成模拟数据（用于测试）
    logger.warning("DataHub未配置，使用模拟数据")
    n = 2000
    np.random.seed(42)
    # ... 生成随机价格序列
```

这意味着过去所有的进化都在对**固定种子（seed=42）的随机噪声**进行拟合，遗传算法过拟合了随机游走，产生了虚假的 10000% 收益率。

### 为什么快

- 模拟数据只有 2000 条
- 没有数据库 I/O
- 随机数据没有真实市场的复杂结构
- 50 代仅需 1.84 秒

### 为什么 Sharpe 高

- 固定种子的随机序列有局部可预测性
- GP 进化会挖掘这些虚假模式
-  capped_return 封顶在 100（即 10000%）

---

## 三、数据库验证

直接查询 TimescaleDB 确认：

```
RB 历史数据: 3360 条
时间范围: 2024-05-24 09:00:00 ~ 2026-05-25 22:00:00
```

**数据库有完整的 2 年真实数据，但进化引擎完全没用到。**

---

## 四、已采取的措施

1. **修复代码**
   - `run_continuous_evolution.py` 已增加 `DataHub` 初始化和传入逻辑
   - 启动时会打印 `DataHub 初始化成功，RB 历史数据: N 条`

2. **清空所有污染数据**
   - `candidates` — 所有因子候选（基于模拟数据拟合的虚假公式）
   - `evolution_tasks` — 16 个进化任务
   - `generation_stats` — **574,168 条世代统计**
   - `baseline_comparison_results` — 基线对比结果
   - `trades` — 关联交易记录

3. **保留资产**
   - `ohlcv_1h` / `ohlcv_1d` — 历史行情数据（真实数据，未受影响）
   - `symbol_switches` — 品种配置

---

## 五、修复后的预期

重启进化引擎后，你应该观察到以下变化：

| 指标 | 模拟数据时代 | 真实数据时代（预期） |
|------|-------------|-------------------|
| 每代耗时 | ~0.03 秒 | 几秒 ~ 十几秒 |
| 收益率 | 10000% | 正常范围（不可能封顶） |
| 夏普比率 | 稳定在 1.068 | 显著降低，可能接近 0 |
| 启动日志 | `DataHub未配置，使用模拟数据` | `DataHub 初始化成功，RB 历史数据: 3360 条` |
| 数据范围 | 2000 条随机序列 | 2024-05 ~ 2026-05 真实行情 |

## 六、教训与检查清单

### 以后每次怀疑数据真实性时，检查：

- [ ] 进化日志中是否出现 `"DataHub未配置，使用模拟数据"`
- [ ] 进化速度是否异常快（< 0.1 秒/代）
- [ ] 收益率是否频繁触及 10000% 封顶
- [ ] 启动脚本是否传入了 `data_hub=_data_hub`

### 永远记住

> **没有连接 DataHub 的进化 = 随机数发生器 + 过拟合。**  
> 再漂亮的夏普比率、再高的收益率，如果底层是随机数据，都是数字垃圾。

---

## 七、重新启动正确流程

1. 确认 `run_continuous_evolution.py` 中 `DataHub` 已正确导入和传入
2. 停止旧的进化进程（Ctrl+C）
3. 重新启动进化引擎：`python scripts/run_continuous_evolution.py`
4. 观察启动日志确认 `DataHub 初始化成功`
5. 等待第一代完成，观察耗时和收益率是否合理
6. 前端刷新（Ctrl+F5）查看新的真实数据进化结果
