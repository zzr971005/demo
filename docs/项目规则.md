# 期货自动进化因子挖掘系统 - 项目规则

## 核心原则

### 1. 数据真实性原则
- **禁止使用模拟价格数据**：所有价格数据必须来自真实历史数据源
- **禁止使用模拟随机数据**：特别是价格、成交量等市场数据
- **必须使用真实历史数据**：TimescaleDB 存储的历史数据或 CSV 备份数据

### 2. 计算准确性原则
- **禁止设置封顶值**：收益率、回撤等指标必须使用真实计算值
- **禁止四舍五入过度**：保留足够精度，如收益率显示 23.45% 而非 23%
- **必须使用原始计算结果**：不人为限制或修改计算结果

## 具体规则

### 数据源规则
1. **历史数据**：优先使用 TimescaleDB 中的真实历史数据
2. **实时数据**：通过 TQSDK 获取真实市场数据
3. **备份恢复**：可从 CSV 备份恢复真实数据
4. **禁止模拟**：禁止生成任何模拟价格、成交量数据

### 计算规则
1. **收益率计算**：`(equity_end - equity_start) / equity_start`
2. **不设封顶**：不人为限制收益率、回撤等指标的上下限
3. **保留精度**：计算结果保留原始精度，显示时合理格式化
4. **真实记录**：所有计算结果必须真实记录到数据库

### 显示规则
1. **收益率显示**：使用 `(total_return * 100).toFixed(2)%` 格式
2. **保留小数**：至少保留 2 位小数，如 23.45%
3. **禁止整数显示**：避免显示如 500% 这样的整数形式

## 代码实现要求

### 移除的逻辑
1. **收益率封顶**：已移除 `max(-1.0, min(1.0, total_return))` 逻辑
2. **模拟价格生成**：已移除 `_mock_update()` 中的随机价格生成
3. **Mock 模式**：已将 `mock=True` 改为 `mock=False`

### 必须使用的逻辑
1. **真实数据源**：TimescaleDB 或 TQSDK 提供的真实数据
2. **原始计算值**：不修改任何计算结果
3. **精确显示**：前端显示保留足够精度

## 监控要求

### 数据质量检查
1. **价格合理性**：检查价格数据是否在合理范围内
2. **收益率合理性**：异常高收益率需要调查原因
3. **数据连续性**：确保历史数据连续无断层

### 计算结果验证
1. **手工验证**：定期手工验证计算结果
2. **交叉验证**：使用不同方法验证关键指标
3. **异常报警**：异常计算结果自动报警

## 违规后果

### 数据违规
- 使用模拟数据导致的所有结果无效
- 需要重新运行所有受影响的计算
- 可能导致策略决策错误

### 计算违规
- 设置封顶值导致指标失真
- 影响因子筛选和排名
- 可能导致实盘交易损失
